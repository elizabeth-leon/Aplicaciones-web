# Parcial 1 – Aplicaciones Web

# Sistema de Gestión de Eventos Deportivos

Este proyecto corresponde a la evaluación del primer parcial de la asignatura de Aplicaciones Web

El sistema fue desarrollado utilizando PHP, Programación Orientada a Objetos (POO), PDO y MySQL. Su finalidad es facilitar el registro y la administración de eventos deportivos, participantes e inscripciones.

Permite realizar operaciones de registro, consulta, actualización y eliminación de información (CRUD), manteniendo organizados los datos mediante una base de datos relacional.

# Tecnologías utilizadas

- PHP
- MySQL
- PDO
- HTML, CSS y JavaScript
